# 拼版选图导出工作台 v5.0.1

一个 Windows 桌面小工具，用于从大量文件夹中**挑图 → 勾选 → 一键导出并自动重命名**，替代手工整理。

## 这个工具能做什么

若你的文件夹中包含大量子文件夹，每个文件夹里都有图片或PDF。以前要一张张复制、改名，现在：

1. 选好源目录和输出目录，点「开始扫描」，左侧列出所有包含图片或PDF的文件夹；
2. 点左侧某个文件夹，右侧按「图片 / PDF」分区显示 200×200 缩略图；
3. 逐张勾选想要的图（勾选状态切走再切回不丢）；
4. 全部挑完后点「开始导出」，自动按 `文件夹名 (1).jpg`、`(2).jpg`… 命名导出到输出目录。

## 如何使用（双击就能用）

1. 双击 `拼版选图导出工作台.exe` 打开程序（第一次启动可能要等几秒）；
2. **源文件夹**：点「浏览…」选择包含图片或PDF的文件夹的目录（例如 `...\已上传`）；
3. **输出文件夹**：点「浏览…」选择要导出到的目录（例如 `...\1200px`）；
4. 点「开始扫描」，左侧会列出所有图片或PDF的文件夹；
   - 文件夹按**自然排序**（`[Angraf 101]` 会排在 `[Angraf 105]` 前面）；
   - 已经导出过的文件夹，名字前会带「✅已处理」标记；
5. 点左侧任意文件夹，右侧显示缩略图；
   - 图片和 PDF 会**分两个区**分别列出，文件按**自然排序**（`page-2` 排在 `page-10` 前）；
   - **（v4 新增）** 如果该文件夹下还有多个子文件夹，右侧会**按子文件夹分组展示**，每个子文件夹一个可折叠区块（标题显示「子文件夹名（N张图 · N个PDF）」）；散落在根目录的图片/PDF 会归入「根目录」分组；没有子文件夹时保持原来的扁平展示；
   - PDF 会**逐页**显示，每页可单独勾选；
   - **（v4 新增）** 每张图片缩略图左上角有「☆ 封面」按钮，点击设为封面（缩略图金色边框高亮），再点一次取消；每个图片或PDF的文件夹最多 1 张封面，设第二张会自动取消第一张；
   - 点缩略图或勾选框都能切换勾选；
   - 也可点底部「◀ 上一个文件夹」「下一个文件夹 ▶」快速切换（到第一/最后一项时对应按钮自动禁用）；
6. **快速切换文件夹**（快速过多个个文件夹时很省事）：
   - 键盘：`↑` / `↓` 方向键切换上一个/下一个文件夹，`PageUp` / `PageDown` 一次翻一屏（约 10 个）；焦点在右侧缩略图区时同样生效；
   - 鼠标手势（默认关闭）：菜单「设置 → 启用鼠标手势（右键拖动切换文件夹）」勾选后，在右侧预览区**按住右键向下拖**切到下一个、**向上拖**切回上一个（拖动约 50 像素才触发，防误触）；
7. 挑完后，看底部「已勾选：N 张」，点「开始导出」；
   - 如果有文件夹**一张都没勾过**，会先弹窗列出这些文件夹（含「✅已处理」标注），问你是否继续；
8. 导出完成后，日志区会显示结果和**跳过清单**。

## 关键规则（请先了解）

- **支持的图片格式**：`jpg / jpeg / png / gif / bmp / avif / webp / tif / tiff / jfif`，另外支持 PDF（逐页渲染）。格式清单统一在 `config.py` 的 `IMAGE_EXTS` 里维护，需要增减在那里改。
- **命名**：导出的图按 `文件夹名 (1).扩展名`、`(2).扩展名`… 递增，顺序 = 图片在前（按文件名）、PDF 页在后（按 文件名→页序）。**扩展名跟随源文件**：gif 导出为 `.gif`、png 导出为 `.png`、webp 导出为 `.webp`… PDF 统一渲染为 `.jpg`。
- **封面（v4 新增）**：被设为封面的图，导出时文件名 = **文件夹名本身**（无编号后缀，如 `Angraf 101 9A52-2 Smerch.jpg`），且作为该文件夹的**第一个文件**导出，其余勾选图从 `(1)` 开始编号。封面**无需勾选**，设了即导出；如果设了封面但没勾其他图，则只导出封面那一张。每个作品文件夹最多 1 张封面。
- **图片原样复制**：普通图片直接复制原文件，因此 **GIF 动画、PNG 透明、WebP/AVIF 原格式都会被完整保留**（不会把 gif 转成静态 jpg）；只有 PDF 才重新渲染成 JPG。
- **不覆盖**：如果输出目录里已经有同名的文件（按实际扩展名判断，如 `文件夹名 (1).gif`），会**跳过**（不会覆盖），并在日志里列出跳过原因。
- **已处理判定**：输出目录里只要存在 `文件夹名 (数字).` 开头的文件，该文件夹就标为「✅已处理」——只是一个提示，不影响你重新勾选导出。
- **PDF 导出**：PDF 会被渲染成清晰的 JPG 再导出（约 144 DPI）。

> 提示：v3 起图片按原始扩展名导出（v2 及更早统一存为 `.jpg`）。如果你之前用旧版导出过 png/webp 等非 jpg 图片，升级后这些图会以新扩展名重新导出一次（因为旧文件叫 `(1).jpg`、新的叫 `(1).png`，不视为同名）；jpg 图片不受影响。

## 从源码运行 / 重新打包（可选，给会一点命令行的人）

依赖：Python 3.10+、PySide6、PyMuPDF、Pillow、PyInstaller。

```bat
pip install PySide6 PyMuPDF Pillow pyinstaller
```

直接运行（不需要打包）：

```bat
python main.py
```

打包成单文件 exe（无控制台窗口）：

```bat
build.bat
```

打包产物在 `dist\拼版选图导出工作台.exe`。

## 源码结构

```
main.py        入口
config.py      常量配置（图片扩展名清单、缩略图尺寸、PDF 缩放、鼠标手势开关等，可改）
scanner.py     扫描源目录、构建作品列表与可导出项（含子文件夹分组）
pdf_render.py  PDF 页渲染（缩略图 + 导出共用）
thumbnail.py   缩略图生成（图片 / PDF 页统一）
exporter.py    导出逻辑（命名、封面、跳过、日志）
ui.py          图形界面 + 后台线程任务（分组展示、封面按钮）
style.py       全局 QSS 样式表（v4 现代扁平化主题，颜色/圆角集中在此）
```

## 已知限制

- 缩略图首次查看某个文件夹时会边加载边显示，图片/PDF 越多越慢一点，之后切回会走缓存、秒开。
- 导出为「原图复制 + 重命名」；PDF 才重新渲染为 JPG。
- 一次扫描结果对应一个源目录；换了源目录需要重新点「开始扫描」。
- 勾选状态保存在内存里，关闭程序后不会保留（下次重新挑）。
- AVIF/WebP 缩略图渲染依赖 Pillow 版本：打包所用 Pillow 12 原生支持两者，可正常显示；万一某个文件无法预览（格式罕见或文件损坏），缩略图区会显示灰色「无法预览」占位图，不会崩溃，也不影响导出。
