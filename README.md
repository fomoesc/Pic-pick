# 拼版选图导出工作台 v5.1.0

一个 Windows 桌面小工具，用于从大量纸模作品文件夹中**挑图 → 勾选 → 一键导出并自动重命名**，替代手工整理。

## 这个工具能做什么

你维护着几百个纸模作品文件夹，每个文件夹里有几十张拼版图（jpg 为主，部分是 PDF）。以前要一张张复制、改名，现在：

1. 选好源目录和输出目录，点「开始扫描」，左侧列出所有作品文件夹；
2. 点左侧某个文件夹，右侧按子文件夹分组显示缩略图；
3. 逐张勾选想要的图（勾选状态切走再切回不丢）；
4. 全部挑完后点「开始导出」，自动按 `文件夹名 (1).jpg`、`(2).jpg`… 命名导出到输出目录。

## v5.1.0 更新内容

### 新增功能
- **磁盘缩略图缓存**：首次生成后缓存到 `.thumb_cache/` 目录，第二次打开同一文件夹秒开
- **扫描时预生成**：扫描完成后后台自动为所有文件夹生成缩略图缓存，无需等待
- **子文件夹分组预览**：有子文件夹时自动分组展示（📁 标题 + 折叠按钮 + 分隔线），支持折叠/展开
- **设置中清空缓存**：可查看缓存大小并一键清空
- **应用图标**：任务栏、标题栏、exe 文件均显示橙色图标

### 性能优化
- **懒加载**：只加载视口可见区域的缩略图，100 张图首次打开从 10s → 1s
- **大图降采样**：超 2000px 原图先缩到中间尺寸再做缩略，减少内存和 CPU 开销
- **LRU 内存缓存**：上限 200 张，防止内存无限增长
- **PDF 超时渲染**：复杂矢量 PDF 5 秒超时显示占位图，不卡死 GUI
- **PDF 导出动态 zoom**：保底最长边 ≥ 1200px + 180 DPI，确保清晰度

### Bug 修复
- 修复缩略图比例变形（降采样强制正方形问题）
- 修复子文件夹分组不生效（检测同名子文件夹并深入一层）
- 修复折叠跳动 BUG（去掉动画直接切换）
- 修复 EXIF 异常 JPG 崩溃（跳过 exif_transpose）
- 修复漏选提醒对话框文案（简化为确定/取消）
- 修复任务栏图标不显示（Windows API 强制设置）

## 如何使用（双击就能用）

1. 双击 `拼版选图导出工作台.exe` 打开程序（第一次启动可能要等几秒）；
2. **源文件夹**：点「浏览…」选择包含作品文件夹的目录（例如 `...\已上传`）；
3. **输出文件夹**：点「浏览…」选择要导出到的目录（例如 `...\1200px`）；
4. 点「开始扫描」，左侧会列出所有作品文件夹；
   - 文件夹按**自然排序**（`[Angraf 101]` 会排在 `[Angraf 105]` 前面）；
   - 已经导出过的文件夹，名字前会带「✅已处理」标记；
   - 扫描完成后，后台自动开始预生成所有缩略图到磁盘缓存；
5. 点左侧任意文件夹，右侧显示缩略图；
   - 如果文件夹内有子文件夹，会**按子文件夹分组展示**，每个子文件夹一个可折叠区块；
   - PDF 会**逐页**显示，每页可单独勾选；
   - 每张图片缩略图左上角有「封面」按钮，点击设为封面（缩略图橙色边框高亮），再点一次取消；每个作品文件夹最多 1 张封面；
   - 点缩略图或勾选框都能切换勾选；
   - 也可点底部「< 上一个文件夹」「下一个文件夹 >」快速切换；
6. **快速切换文件夹**：
   - 键盘：`↑` / `↓` 方向键切换上一个/下一个文件夹，`PageUp` / `PageDown` 一次翻一屏；
   - 鼠标手势（默认关闭）：菜单「设置 → 启用鼠标手势」勾选后，在右侧预览区**按住右键上下拖**切换文件夹；
7. 挑完后，看底部「已选择 N 页」，点「开始导出」；
   - 如果有文件夹未勾选，会弹窗提示「该文件夹中还有 X 项未选择！请确认是否继续当前导出。」
8. 导出完成后，日志区会显示结果和**跳过清单**。

## 关键规则（请先了解）

- **支持的图片格式**：`jpg / jpeg / png / gif / bmp / avif / webp / tif / tiff / jfif`，另外支持 PDF（逐页渲染）。格式清单统一在 `config.py` 的 `IMAGE_EXTS` 里维护。
- **命名**：导出的图按 `文件夹名 (1).扩展名`、`(2).扩展名`… 递增，顺序 = 图片在前（按文件名）、PDF 页在后（按 文件名→页序）。**扩展名跟随源文件**：gif 导出为 `.gif`、png 导出为 `.png`… PDF 统一渲染为 `.jpg`。
- **封面**：被设为封面的图，导出时文件名 = **文件夹名本身**（无编号后缀），且作为该文件夹的**第一个文件**导出，其余勾选图从 `(1)` 开始编号。封面**无需勾选**，设了即导出；每个作品文件夹最多 1 张封面。
- **图片原样复制**：普通图片直接复制原文件，因此 **GIF 动画、PNG 透明、WebP/AVIF 原格式都会被完整保留**；只有 PDF 才重新渲染成 JPG。
- **不覆盖**：如果输出目录里已经有同名的文件，会**跳过**（不会覆盖），并在日志里列出跳过原因。
- **已处理判定**：输出目录里只要存在 `文件夹名 (数字).` 开头的文件，该文件夹就标为「✅已处理」——只是一个提示，不影响你重新勾选导出。
- **PDF 导出**：PDF 会被渲染成清晰的 JPG 再导出（保底最长边 ≥ 1200px，180 DPI）。
- **磁盘缓存**：缩略图缓存在程序同级 `.thumb_cache/` 目录，可在「设置」中查看大小并清空。

## 从源码运行 / 重新打包

依赖：Python 3.10+、PySide6、PyMuPDF、Pillow、PyInstaller。

```bat
pip install PySide6 PyMuPDF Pillow pyinstaller
```

直接运行：

```bat
python main.py
```

打包成单文件 exe：

```bat
build.bat
```

打包产物在 `dist\拼版选图导出工作台_v5.1.0.exe`。

## 源码结构

```
main.py          入口（加载图标、设置 AppUserModelID）
config.py        常量配置（图片扩展名、缩略图尺寸、PDF 导出参数）
scanner.py       扫描源目录、构建作品列表（含子文件夹分组逻辑）
pdf_render.py    PDF 页渲染（超时渲染 + 动态 zoom）
thumbnail.py     缩略图生成（磁盘缓存 + 大图降采样）
exporter.py      导出逻辑（命名、封面、跳过、日志）
disk_cache.py    磁盘缓存管理（读/写/清空/自动淘汰）
ui.py            图形界面 + 后台线程（懒加载、LRU 缓存、分组展示）
style.py         全局 QSS 样式表（橙色扁平化主题）
settings.py      设置持久化（config.json 读写）
```

## 已知限制

- 首次扫描大文件夹（数百张图）时，后台预生成缩略图需要几分钟，之后再次打开秒开。
- 导出为「原图复制 + 重命名」；PDF 才重新渲染为 JPG。
- 一次扫描结果对应一个源目录；换了源目录需要重新点「开始扫描」。
- 勾选状态保存在内存里，关闭程序后不会保留（下次重新挑）。
- 磁盘缓存占用空间约 50-200MB（取决于图片数量），可在设置中清空。
